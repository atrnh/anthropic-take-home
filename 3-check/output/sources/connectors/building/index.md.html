The legacy HTTP+SSE transport is being deprecated in favor of Streamable HTTP.33 34 ### Authentication features35 36 * Supports the [2025-03-26](https://modelcontextprotocol.io/specification/2025-03-26/basic/authorization), [2025-06-18](https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization), and [2025-11-25](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization) auth specifications37 * Dynamic Client Registration (DCR) enabled38 * OAuth callback: `https://claude.ai/api/mcp/auth_callback` (hosted surfaces); loopback redirect for Claude Code — see [callback URLs](/docs/connectors/building/authentication#callback-urls)39 * Token refresh and expiry support40 * Custom credentials for non-DCR servers41 42 ## Protocol features43 44 ### Supported45 46 * [Tools](https://modelcontextprotocol.io/specification/latest/server/tools), [prompts](https://modelcontextprotocol.io/specification/latest/server/prompts), and [resources](https://modelcontextprotocol.io/specification/latest/server/resources)47 * [Text](https://modelcontextprotocol.io/specification/latest/schema#textcontent) and [image-based](https://modelcontextprotocol.io/specification/latest/server/tools#image-content) tool results48 * [Text](https://modelcontextprotocol.io/specification/latest/schema#textresourcecontents) and [binary](https://modelcontextprotocol.io/specification/latest/schema#blobresourcecontents) resources49 50 ### Not yet supported51 52 * Resource subscriptions53 * Sampling54 * Advanced/draft capabilities55 56 ## Technical specifications57 58 | Constraint                             | Limit                                                    |59 | -------------------------------------- | -------------------------------------------------------- |60 | Claude.ai/Desktop max tool result size | \~150,000 characters                                     |61 | Claude Code max tool result size       | 25,000 tokens (configurable via `MAX_MCP_OUTPUT_TOKENS`) |62 | Claude Code timeout                    | Configurable via `MCP_TOOL_TIMEOUT`                      |63 | Claude.ai/Desktop tool call timeout    | 240 seconds (4 minutes) per tool call                    |64 | Transport protocol                     | Streamable HTTP (legacy HTTP+SSE being deprecated)       |65 66 ## Testing your server67 68 1.
