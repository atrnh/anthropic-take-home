What is MCP?12 13 MCP provides a standardized way for AI assistants like Claude to:14 15 * Connect to external tools and services16 * Access data from various sources17 * Perform actions on behalf of users18 * Maintain security and user control19 20 ## How MCP works21 22 ### Local vs remote servers23 24 | Type           | Description            | Use Case                          |25 | -------------- | ---------------------- | --------------------------------- |26 | **Local MCP**  | Runs on your device    | Desktop integrations, local tools |27 | **Remote MCP** | Hosted on the internet | Web services, cloud applications  |28 29 ### Key components30 31 * **Tools**: Actions Claude can perform (search, create, modify)32 * **Resources**: Data Claude can access (files, documents, records)33 * **Prompts**: Predefined interactions for specific tasks34 35 ## Security model36 37 ### User control38 39 * You authenticate each connector individually40 * Permissions mirror your access on the external service41 * You can disconnect at any time42 43 ### Tool hints44 45 All MCP tools must declare:46 47 * [`readOnlyHint`](https://modelcontextprotocol.io/specification/latest/schema#toolannotations-readonlyhint): Tool only reads data48 * [`destructiveHint`](https://modelcontextprotocol.io/specification/latest/schema#toolannotations-destructivehint): Tool can modify or delete data49 50 This helps Claude and users understand what actions are possible.51 52 ## Building with MCP53 54 The [MCP documentation](https://modelcontextprotocol.io/docs) is the source of truth for building MCP servers.55 56 ### For developers57 58 * Open specification at [modelcontextprotocol.io](https://modelcontextprotocol.io)59 * [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) and [Python SDK](https://github.com/modelcontextprotocol/python-sdk) available60 * Cloudflare hosting support with OAuth61 62 ### Submitting to directory63 64 Organizations can [submit MCP servers](/docs/connectors/building/submission) to the Connectors Directory for broader availability.65 66 ##
