On Team and Enterprise plans, an organization Owner must enable the connector before members can connect.13 </Note>14 15 ## Capabilities16 17 With this connector, Claude can:18 19 * **Search and analyze documents** across SharePoint sites and OneDrive libraries20 * **Access email threads** and analyze Outlook communications21 * **Review meeting information** from Teams Calendar22 * **Pull insights** from Teams Chat discussions23 * **Send and manage email**, including drafts, labels, mail filters, and automatic replies24 * **Manage calendar events** and find meeting times25 * **Create and update files** in SharePoint26 27 ## Setup requirements28 29 On Free, Pro, and Max plans, no organization-level setup is needed. Connect from **Customize > Connectors** in claude.ai. A Microsoft Entra Global Administrator still needs to grant one-time tenant consent for your Microsoft organization.30 31 ### Prerequisites32 33 * A work or school Microsoft account on a Microsoft Entra tenant (personal accounts such as outlook.com, hotmail.com, or live.com aren't supported)34 * Claude user with Owner or Primary Owner role (Team and Enterprise plans)35 * Global Administrator access to Microsoft Entra tenant36 * Active Microsoft 365 accounts for all users (Team and Enterprise plans)37 38 ### Phase 1: Administrator setup39 40 **Automatic Setup (Recommended):**41 42 1. Navigate to **Organization settings > Connectors**43 2. Select **Add**, then **All available**44 3. Find Microsoft 365 and select "Add to your team"45 4. Connect individually and grant organization-wide permissions46 5. (Optional) Restrict user access or revoke specific permission scopes47 48 ### Phase 2: User enablement49 50 Once enabled by administrators, team members:51 52 1. Navigate to **Customize > Connectors**53 2. Find Microsoft 365 and click "Connect"54 3. Authenticate with credentials55 56 ## Usage57 58 Ask Claude questions requiring Microsoft 365 data, or ask Claude to take an action such as sending an email or updating a file. Claude automatically detects and uses the necessary tools.59 60 ### Example queries61 62 * "Find the Q4 strategic planning document in SharePoint"63 * "Summarize email conversations about the product launch"64 * "What discussions happened in Teams about the marketing campaign?"65 * "Review meeting notes from last week's leadership sync"66 * "Draft a reply to the latest email about the vendor contract"67 * "Schedule a 30-minute sync with the design team next week"68 69 ## What you can access70 71 | Service                 | Capabilities                                                                                               |72 | ----------------------- | ---------------------------------------------------------------------------------------------------------- |73 | **SharePoint/OneDrive** | Search and analyze documents; create and update files in SharePoint                                        |74 | **Outlook**             | Search email threads and archived emails; send and manage mail; create, update, and delete calendar events |75 | **Teams Calendar**      | Review meeting summaries and attendance                                                                    |76 | **Teams Chat**          | Access channel and chat discussions                                                                        |77 78 ## Write actions79 80 Claude can take actions in Outlook and SharePoint: send mail and manage drafts; organize mail with labels, filters, and trash; set automatic replies; create, update, and delete calendar events; and create and update files in SharePoint. Read and search tools work the same whether or not write actions are enabled.81 82 Write actions are controlled by your organization's administrators in two places:83 84 1. **Approve the write permissions.** If your tenant's consent for the connector covers only read permissions, a Microsoft Entra Global Administrator or Application Administrator approves the updated permission set (mail, calendar, mailbox settings, and file writes) under **Enterprise applications** in the Entra admin center. This is a one-time action per tenant.85 2. **Turn on write actions.** If write actions are off for your organization, administrators turn them on for all users in the Microsoft 365 connector configuration, or enable them for specific users with role-based access control (beta).86 87 Claude cannot attach files to the drafts it creates and cannot send Teams messages.88 89 For setup steps, see [Connect to Microsoft 365](https://support.claude.com/en/articles/15183774-connect-to-microsoft-365) and [Set up the Microsoft 365 connector](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector) in the help center. The [Microsoft 365 connector security guide](https://support.claude.com/en/articles/12684923-microsoft-365-connector-security-guide) covers the permission model.90 91 ## Permissions92 93 <Note>94   All permissions are delegated: Claude acts on behalf of users and can only access and change content that you already have permission to access and change in Microsoft 365.
