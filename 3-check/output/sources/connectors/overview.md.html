1 > ## Documentation Index2 > Fetch the complete documentation index at: https://claude.com/docs/llms.txt3 > Use this file to discover all available pages before exploring further.4 5 # Connectors overview6 7 > Connect Claude to external tools, data, and UI through MCP8 9 Connectors extend Claude's capabilities by connecting it to external tools and data sources. They are powered by the [Model Context Protocol (MCP)](/docs/connectors/building/mcp), an open standard created by Anthropic that provides a unified way for AI applications to interact with the outside world.10 11 ## How connectors work12 13 Connectors can do two things:14 15 * **Provide tools and information** — Give Claude access to external data and the ability to take actions (search files, read emails, create issues, etc.)16 * **Surface UI components** — Render interactive visual elements directly in the conversation through [MCP Apps](/docs/connectors/building/mcp-apps/getting-started)17 18 <Note>19   **Building for Claude?** Most partners ship both a remote MCP server and a plugin that wraps it with skills. See [what to build](/docs/connectors/building/what-to-build) for the decision guide.20 </Note>21 22 ## Types of connectors23 24 ### Prebuilt integrations25 26 Anthropic provides first-party integrations with popular services like Google Drive, Gmail, Google Calendar, GitHub, Slack, and Microsoft 365. These are ready to use with no setup beyond authentication. See [Getting started](/docs/connectors/getting-started) for setup instructions.27 28 ### Remote MCP servers29 30 [Remote MCP servers](/docs/connectors/custom/remote-mcp) communicate with Claude over the internet, giving it access to cloud-hosted tools and data. You can connect to existing remote MCP servers or build your own for any tool or service.31 32 ### MCP Apps33 34 [MCP Apps](/docs/connectors/building/mcp-apps/getting-started) allow MCP servers to display interactive UI elements in conversational MCP clients. Rather than only returning text, an MCP App can render charts, maps, forms, and other visual components directly in the chat. See the [design guidelines](/docs/connectors/building/mcp-apps/design-guidelines) and [cross-platform compatibility](/docs/connectors/building/mcp-apps/cross-compatibility) docs for building MCP Apps.35 36 ### MCP Bundles37 38 [MCP Bundles (MCPB)](/docs/connectors/custom/desktop-extensions) package MCP servers with their dependencies for distribution as desktop extensions. MCPB handles cross-platform compatibility, dependency management, code signing, and centralized version updates — making it suitable for enterprise deployment of local MCP servers to Claude Desktop.39 40 ### Self-serve local MCP41 42 Local MCP servers distributed through third-party package registries like npm or PyPI cannot be listed directly in the Connectors Directory. To distribute a local server, package it as an [MCPB](/docs/connectors/building/mcpb) for the Desktop Extensions gallery, or bundle it in a [plugin](/docs/plugins/overview) using `.mcp.json` and submit it to the [plugin directory](/docs/plugins/submit).43 44 ## Ways to connect45 46 ### Connectors directory47 48 The [Connectors Directory](/docs/connectors/directory) is an open catalog of MCP servers from Anthropic and third-party developers, available across all Claude products. It includes both connectors that Anthropic has verified and community connectors; see [connector verification](/docs/connectors/verification) to learn what each label means.49 50 ### Third-party connectors51 52 You can build and connect your own MCP servers for proprietary tools or workflows. See [Third-party Connectors](/docs/connectors/custom/remote-mcp) for remote MCP and [Desktop Extensions](/docs/connectors/custom/desktop-extensions) for local integrations.53 54 ## Related concepts55 56 ### Plugins57 58 [Plugins](/docs/plugins/overview) combine MCP connectors, [Skills](/docs/skills/overview), slash commands, and sub-agents into shareable capability packages. They are available in Claude Code and Cowork. You can also [submit your plugin](/docs/plugins/submit) to the plugin directory.59 60 ## Platform availability61 62 Prebuilt integrations and directory connectors work across all Claude products:63 64 * **Claude.ai** — Full remote MCP support & MCP Apps65 * **Claude Desktop** — Full MCP support and local desktop extensions66 * **Claude Mobile** — Remote MCP access67 * **Claude Code** — Remote MCP access and plugins68 * **Claude Cowork** — Full MCP and plugin support69 70 ## Next steps71 72 <Columns cols={2}>73   <Card title="Getting started" icon="rocket" href="/docs/connectors/getting-started">74     Set up your first connector.75   </Card>76 77   <Card title="Connectors directory" icon="grid-2" href="/docs/connectors/directory">78     Browse verified and community integrations.79   </Card>80 81   <Card title="Build a connector" icon="code" href="/docs/connectors/building/index">82     Create your own MCP server.83   </Card>84 85   <Card title="MCP Apps" icon="window" href="/docs/connectors/building/mcp-apps/getting-started">86     Build UI components for Claude.87   </Card>88 89   <Card title="MCP in Claude Code" icon="terminal" href="https://code.claude.com/docs/en/mcp-quickstart">90     Add an MCP server to Claude Code from the command line.91   </Card>92 93   <Card title="Claude Code documentation" icon="terminal" href="https://code.claude.com/docs">94     Install, configure, and use the Claude Code CLI.95   </Card>96 </Columns>
