Installing one can add skills, MCP connectors, subagents, slash commands, or hooks in a single step. Plugins come from the marketplace, from your organization, or from a file you upload.10 11 Plugins are available in Cowork and Code. They aren't used in Chat.12 13 ## What a plugin can contain14 15 A plugin's manifest declares any combination of the following.16 17 | Component  | What it adds                                               |18 | ---------- | ---------------------------------------------------------- |19 | Skills     | Reusable instructions that teach Claude a workflow         |20 | Connectors | MCP servers that give Claude access to an external service |21 | Agents     | Specialized subagents Claude can delegate to               |22 | Hooks      | Scripts that run at defined points in a session            |23 24 After installing, open the plugin to see what it provides. Skills and agents appear as tabs; connectors and hooks have their own pages.25 26 ## Install a plugin27 28 Open **Customize** in the sidebar, then **Plugins**.29 30 <Steps>31   <Step title="Browse the marketplace">32     Select **Browse plugins** to see available plugins. The default marketplace33     is Anthropic's official catalog; you can add other marketplaces by URL.34   </Step>35 36   <Step title="Install">37     Select a plugin and click **Install**. If the plugin includes a connector38     that needs authentication, you're prompted to sign in.39   </Step>40 41   <Step title="Review components">42     Open the installed plugin to see its skills, connectors, agents, and hooks.43     Enable or disable individual components as needed.44   </Step>45 </Steps>46 47 To install from a file instead, select the upload option on the Plugins page and select the plugin package.48 49 ## Use a Git repository as a marketplace50 51 A Git repository that contains plugin packages can serve as a marketplace. This is the typical way teams distribute their own plugins without publishing to the public catalog. Repositories on GitHub (including GitHub Enterprise) are supported; public repositories on GitLab and Bitbucket also work.52 53 <Steps>54   <Step title="Add the repository">55     On the Plugins page, select **Add marketplace** and enter the repository's56     URL. Cowork accepts the standard `https://github.com/owner/repo` form and57     the `owner/repo` shorthand for GitHub.58   </Step>59 60   <Step title="Install plugins from it">61     Plugins defined in the repository appear alongside plugins from other62     marketplaces. Install them the same way.63   </Step>64 </Steps>65 66 Click **Update** on a marketplace to pull the latest plugins from its repository.67 68 For administrator-managed marketplaces, see [MCP, plugins, skills, and hooks](/docs/cowork/3p/extensions) in the deployment guide.69 70 ## Limits71 72 The following are the default limits for plugin packages and marketplaces.73 74 | Limit                              | Value  |75 | ---------------------------------- | ------ |76 | Plugin package size (uncompressed) | 200 MB |77 | Files per plugin package           | 5,000  |78 | Marketplace repository archive     | 512 MB |79 | Plugins per marketplace            | 500    |80 | Marketplaces you can add           | 25     |81 82 The in-app skill viewer previews individual files up to 1 MB. Larger files appear in the file list as "too large to preview" but are still available to Claude at runtime.83 84 ## Plugins managed by your organization85 86 On Team and Enterprise plans, administrators can require certain plugins for everyone in the organization. Required plugins install automatically and show **This plugin is required by your organization**; you can't remove them.87 88 For how administrators provision plugins, see [MCP, plugins, skills, and hooks](/docs/cowork/3p/extensions) in the deployment guide.89 90 ## Update and remove plugins91 92 Cowork checks for plugin updates from the marketplace they came from. If you've edited a plugin's files locally, Cowork detects the change and warns you before an update would overwrite it.93 94 To remove a plugin you installed, open it under **Customize → Plugins** and click **Uninstall**. Organization-managed plugins can only be removed by an administrator.95 96 ## Related97 98 * [Plugins overview](/docs/plugins/overview) for how plugins work across Claude products99 * [Submit a plugin](/docs/plugins/submit) to publish your own to the marketplace100 * [MCP, plugins, skills, and hooks](/docs/cowork/3p/extensions) for administrator provisioning
