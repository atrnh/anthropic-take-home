This guide explains how to create, structure, and test your own skills.10 11 Skills can range from simple instruction sets to multi-file packages with executable code. Effective skills:12 13 * Solve a specific, repeatable task14 * Have clear instructions Claude can follow15 * Include examples when helpful16 * Define when they should be used17 * Focus on one workflow rather than trying to do everything18 19 <Note>20   Skills follow the [Agent Skills specification](https://agentskills.io/specification) — see the specification for more in-depth information.21 </Note>22 23 ## Directory structure24 25 A skill is a directory containing at minimum a `SKILL.md` file:26 27 ```28 brand-guidelines/29 ├── SKILL.md30 ├── scripts/        # Optional: executable code31 ├── references/     # Optional: additional documentation32 └── assets/         # Optional: templates, images, data files33 ```34 35 The directory name must match the `name` field in your `SKILL.md`.36 37 ## Creating a `SKILL.md` file38 39 The `SKILL.md` file must start with YAML frontmatter containing required metadata, followed by markdown instructions.40 41 ### Required fields42 43 ```markdown SKILL.md theme={null}44 ---45 name: brand-guidelines46 description: Apply Acme Corp brand guidelines to presentations and documents, including official colors, fonts, and logo usage.47 ---48 ```49 50 **name**: Lowercase letters, numbers, and hyphens only. Maximum 64 characters. Must match the directory name.51 52 **description**: Explains what the skill does and when to use it. Claude uses this to determine when to invoke your skill. Maximum 1,024 characters, the same limit as the [Agent Skills specification](https://agentskills.io/specification).53 54 ### Markdown body55 56 After the frontmatter, write markdown instructions for Claude. Include:57 58 * Step-by-step procedures59 * Examples of inputs and outputs60 * Templates or formatting requirements61 * Edge cases to handle62 63 Keep your main `SKILL.md` under 500 lines. Move detailed reference material to separate files.64 65 ### Complete example66 67 ```markdown SKILL.md theme={null}68 ---69 name: brand-guidelines70 description: Apply Acme Corp brand guidelines to presentations and documents, including official colors, fonts, and logo usage.71 ---72 73 # Brand Guidelines74 75 Apply these standards when creating presentations, documents, or marketing materials for Acme Corp.76 77 ## Brand colors78 79 - Primary: #FF6B35 (Coral)80 - Secondary: #004E89 (Navy Blue)81 - Accent: #F7B801 (Gold)82 - Neutral: #2E2E2E (Charcoal)83 84 ## Typography85 86 - Headers: Montserrat Bold87 - Body text: Open Sans Regular88 - Size guidelines: H1 32pt, H2 24pt, Body 11pt89 90 ## Logo usage91 92 Use the full-color logo on light backgrounds, white logo on dark backgrounds. Maintain minimum spacing of 0.5 inches around the logo.93 94 ## When to apply95 96 Apply these guidelines when creating:97 - PowerPoint presentations98 - Word documents for external sharing99 - Marketing materials100 - Reports for clients101 102 See the [assets/](assets/) folder for logo files and font downloads.103 ```104 105 ## Adding resources106 107 For content too detailed for `SKILL.md`, add files to your skill directory:108 109 * **`references/`**: Additional documentation Claude can read when needed110 * **`assets/`**: Templates, images, lookup tables, schemas111 * **`scripts/`**: Executable code (see below)112 113 Reference these files in `SKILL.md` so Claude knows when to load them. Keep files focused—smaller files mean less context usage.114 115 ## Adding scripts116 117 Skills can include executable code in Python, JavaScript/Node.js, or Bash. Place scripts in the `scripts/` directory.118 119 Claude can install packages from standard repositories (PyPI, npm) when loading skills. Declare dependencies in your frontmatter:120 121 ```markdown SKILL.md theme={null}122 ---123 name: data-analysis124 description: Analyze CSV files and generate visualizations.125 dependencies: python>=3.8, pandas>=1.5.0, matplotlib126 ---127 ```128 129 ## Packaging your skill130 131 To upload a skill to Claude:132 133 1. Ensure the directory name matches your skill's `name` field134 2. Create a ZIP file containing the skill directory135 136 **Correct structure:**137 138 ```139 my-skill.zip140 └── my-skill/141     ├── SKILL.md142     └── scripts/143 ```144 145 **Incorrect structure:**146 147 ```148 my-skill.zip149 ├── SKILL.md  # files directly in ZIP root150 └── scripts/151 ```152 153 ## Testing your skill154 155 ### Before uploading156 157 1. Review `SKILL.md` for clarity158 2. Verify the description accurately reflects when Claude should use the skill159 3. Check that all referenced files exist160 4. Validate using `skills-ref validate ./my-skill` ([validation tool](https://github.com/agentskills/agentskills/tree/main/skills-ref))161 162 ### After uploading163 164 1. Enable the skill in **Customize > Skills**165 2. Try prompts that should trigger it166 3. Review Claude's thinking to confirm it's loading the skill167 4. Iterate on the description if Claude isn't using it when expected168 169 ## Best practices170 171 **Keep it focused**: Create separate skills for different workflows. Multiple focused skills compose better than one large skill.172 173 **Write clear descriptions**: Be specific about when the skill applies. Include keywords that help Claude identify relevant tasks.174 175 **Start simple**: Begin with markdown instructions before adding scripts.176 177 **Use examples**: Include example inputs and outputs to help Claude understand what success looks like.178 179 **Test incrementally**: Test after each significant change.180 181 **Leverage composability**: Claude can use multiple skills together automatically.182 183 ## Security considerations184 185 * Don't hardcode sensitive information (API keys, passwords)186 * Review any downloaded skills before enabling them187 * Use MCP connections for external service access188 189 ## Example skills190 191 See [github.com/anthropics/skills](https://github.com/anthropics/skills/tree/main/skills) for example skills you can use as templates.192 193 ## Related topics194 195 <Columns cols={2}>196   <Card title="Skills in Claude Code" icon="terminal" href="https://code.claude.com/docs/en/skills">197     Create and test skills from the Claude Code CLI, including the `/skills` manager.198   </Card>199 200   <Card title="Distribute as a plugin" icon="puzzle-piece" href="/docs/plugins/submit">201     Package your skill for the plugin directory.202   </Card>203 </Columns>
