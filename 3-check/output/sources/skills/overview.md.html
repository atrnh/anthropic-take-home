Each skill has a `SKILL.md` file that defines when it should be activated and what instructions Claude should follow.10 11 ## Availability12 13 Skills are available for users on Pro, Max, Team, and Enterprise plans. The Skills feature requires code execution to be enabled.14 15 ## How skills work16 17 Skills use progressive disclosure to manage context efficiently:18 19 1. **Metadata loading**: Claude reads skill names and descriptions at startup (\~100 tokens each)20 2. **Activation**: When a task matches a skill's description, Claude loads the full `SKILL.md` content21 3. **Resource loading**: Additional files (scripts, references) are loaded only when needed22 23 This approach prevents context window overload while providing specialized capabilities on demand.24 25 ## Types of skills26 27 * **Anthropic skills**: Pre-built skills for document creation (Excel, Word, PowerPoint, PDF) that activate automatically when relevant.28 * **Partner skills**: Skills from partners like Notion, Figma, and Atlassian designed for seamless MCP connector integration.29 * **Organization-provisioned skills**: Skills deployed organization-wide by Team and Enterprise administrators.30 * **Custom skills**: Skills you create for specialized workflows—generating emails, applying brand guidelines, integrating with tools like JIRA or Linear, and more!31 32 ##
