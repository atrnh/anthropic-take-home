# Claude Docs improvements

A documentation improvement project focused on skills, plugins, and connectors
across [Claude Docs](https://claude.com/docs).

The work covers information architecture, editorial standards, and automated
checks to help readers find and follow the right instructions.

Start with the [draft audit memo](docs/1-audit/audit-memo.md). Its supporting
[disposition ledger](docs/1-audit/disposition-ledger.md) covers all 54 snapshot
pages, and the [proposed IA](docs/1-audit/proposed-ia.md) describes migration.

See the [roadmap](docs/roadmap.md) for planned deliverables.
