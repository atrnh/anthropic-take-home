# Claude Docs improvements

A documentation improvement project focused on skills, plugins, and connectors
across [Claude Docs](https://claude.com/docs).

The work covers information architecture, editorial standards, and automated
checks to help readers find and follow the right instructions.

Start with the [audit memo](docs/1-audit/README.md) for the prioritized findings,
proposed navigation, migration plan, and measurement approach. It links to the
supporting drafts and the disposition ledger covering all 54 snapshot pages.

See the [roadmap](docs/roadmap.md) for planned deliverables.

The [automated-check prototype](docs/3-check/README.md) includes a reproducible
54-page run, reviewed findings, and an evaluation of its mistakes and limitations.
