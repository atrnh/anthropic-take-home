# Install a plugin

Add a plugin for your own use in Cowork. A [plugin](https://claude.com/docs/plugins/overview)
packages capabilities such as skills and tools so you can install them together.

## Choose your instructions

The available plugins and installation behavior depend on how your organization
provides Claude. Choose the guide that matches the Claude account you are using
for this task.

### How to check

Check the setup instructions your organization gave you for Claude. If they
identify **Claude for Government**, choose that guide. If they direct you to the
general Cowork guide, choose **Cowork — general guide**.

If you set up Claude yourself, start with the general Cowork guide. If your
organization set it up and the instructions do not identify the guide, ask the
person who manages Claude:

> Which plugin installation guide applies to my Claude account: the general
> Cowork guide, Claude for Government, or another setup?

If neither guide matches, ask that person for the relevant installation
instructions. The absence of a Government label does not identify your setup.
You can also choose **Show both guides** to compare the instructions.
