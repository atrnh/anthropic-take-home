It saves the current session as Markdown in `transcripts/<date>-<session-id-prefix>.md`. Running it again in the same session overwrites that file. It only runs when you type the command, and it doesn't commit the dump.

I tested it on this session: 16 messages, about 750 lines. I deleted that test dump so the first real one comes from you.

What it does to the transcript:
- **Removes** system reminders, sub-agent side conversations and thinking blocks. Thinking blocks are stored empty in the log anyway.
- **Redacts** email addresses and your account and organization IDs.
- **Truncates** tool output to 2,000 characters per result, collapsed so readers can expand it.

Two limitations:
- **Redaction only catches those patterns.** It won't catch secrets pasted into a command or a file path that identifies you, so skim a dump before you submit it.
- **Only this project's sessions work.** The script looks for transcripts in this repo's folder under `~/.claude/projects/`, so it won't find chats started in other folders.
